# Repositorio turma 42 Spring boot

Esse Repositorio tem como intuito armazenar os projetos voltado a disciplina de desenvolvimento web full mvc.

Essa turma vera varios exemplos.

Iremos ultilizar as tecnologias para realizar o desenvolvimento de projetos voçtado a web. Essas tecnologias são:

- Java
- SpringBoot
- Hibernate
- JPA
- Bootstrap
- PostgreSQL
